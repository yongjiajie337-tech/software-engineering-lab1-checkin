# 简单签到系统

软件工程导论实验一的自建本地演示项目。目标是练习项目运行、Git 版本控制和 AI 辅助编程。

## 当前功能

- 输入姓名或测试昵称，生成签到记录。
- 显示签到时间，最新记录排在最前面。
- 刷新页面后，从同一浏览器恢复记录。
- 拒绝空白输入。
- 同一昵称当天只允许签到一次，重复签到时提示“今天已签到”，记录数不增加。

本次 AI 功能扩展由学生选择“防止当天重复签到”。昵称去掉首尾空格后完全相同才视为同一昵称；日期按本机本地日期判断。不同昵称或隔天可以正常签到，基础版已有的记录保留。

## 运行方法

只需 Python 3 和浏览器，不需要安装第三方依赖。在本目录打开 PowerShell：

```powershell
python hello_ai.py
python -m http.server 8765 --bind 127.0.0.1
```

第一条命令用于最小 AI 编程程序，预期输出 `Hello, AI 编程！`。

第二条命令启动本机静态文件服务。保持终端打开，在浏览器访问：

<http://127.0.0.1:8765/>

停止服务时，在启动它的终端按 `Ctrl+C`。若该端口已被占用，可改为 8766，并同步修改访问地址；不同端口的浏览器记录互不共享。

## 技术说明与边界

页面使用 HTML、CSS 和原生 JavaScript。签到数据保存在当前浏览器的 localStorage 中；本机 Python 服务只负责提供静态文件，不接收或保存签到数据。

本项目没有账户认证、服务端数据库或多人共享能力。签到时间由本机时钟产生，姓名或昵称由操作者输入，不验证身份。当天防重只适用于同一浏览器内的记录；不同人使用同一昵称也会被视为重复。请使用测试昵称完成演示。
